Glossary

Every acronym, part name and piece of team slang you will meet on this site and in the code, in a sentence or two, with links to where each one is explained properly.

How to use it
  • Type in the search box: it searches the names, expansions, the code names listed under Also and the definitions. Results stay in A to Z order; the closest name match is marked, and Enter jumps to it.
  • Tap a letter to jump, or a part to see only its terms.
  • Each entry ends with links to the chapter sections that explain it. Read those for the numbers and the why.
  • Link straight to one entry with glossary.html#term- and its name, like #term-ekf.

Names in code font are written exactly as in the code, so you can search the repos for them. A linked word inside a definition has its own entry here, and the small tag beside each term names the part of the site it belongs to.
